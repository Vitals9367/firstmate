# Matt Pocock skills

This directory is a vendored copy of the skills from https://github.com/mattpocock/skills, release v1.3 (commit `d81f3a1`).
The skills are by Matt Pocock and are used under the MIT license in [`LICENSE`](LICENSE).
The copy keeps the upstream categories: `engineering`, `productivity`, `misc`, and `in-progress`.
The upstream `deprecated` category is not copied.

The copy does not update automatically.
To update it, copy the upstream `skills/` categories into this directory again and update the release and commit above.
To get automatic updates in Claude Code instead, install the upstream plugin with `claude plugins install mattpocock-skills`.
Do not install both into one agent, because each skill then loads twice.
